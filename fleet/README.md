# Fleet

Kit and facts shared by more than one aircraft. Anything true of one aircraft only
belongs in that aircraft's folder. Decisions: [`decisions.md`](decisions.md). Open:
[`open-questions.md`](open-questions.md).

## Shared kit

| Item | What is known | Source of the fact |
|---|---|---|
| RC link | ExpressLRS 2.4 GHz. Transmitter is a RadioMaster with an internal ELRS module; model TBC. Bee35 receiver: RadioMaster RP3 V2 | Bee35 [`docs/bom.md`](../aircraft/bee35/docs/bom.md), [OQ-02](../aircraft/bee35/docs/open-questions.md) |
| Video | Walksnail Avatar HD on the Bee35. Goggles model, and whether the other aircraft share the system, TBC | Bee35 `docs/bom.md` |
| Battery packs | 4S1P Molicel P45B 21700 packs, the existing fleet standard; the Bee35 was kept 4S for commonality with them | Bee35 [DEC-03](../aircraft/bee35/docs/decisions.md) |
| Firmware | iNav on the 5" and the Bee35, chosen for commonality. Holybro: unknown | Bee35 [DEC-01](../aircraft/bee35/docs/decisions.md) |
| Printed parts | Every printable part comes off the family printer; materials and profiles are in wk-robotics [`docs/common.md`](https://github.com/WayneKennedy/wk-robotics/blob/main/docs/common.md#printing) | wk-robotics |

Everything else about the fleet, charger, tooling, field procedures, is not yet recorded
([F-OQ-01](open-questions.md)).
